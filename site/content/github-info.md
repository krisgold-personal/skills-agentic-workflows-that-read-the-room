## Recent updates worth knowing

- **Copilot code review can now approve pull requests.** Copilot's automated review can mark a PR as approved when it finds no blocking issues, speeding up low-risk merges. Source: [GitHub Changelog, 2026-09-01](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests).
- **Auto-resolution and analysis updates in Copilot code review.** Copilot can now automatically resolve certain review comments and provides deeper analysis on flagged issues. Source: [GitHub Changelog, 2026-09-11](https://github.blog/changelog/2026-09-11-auto-resolution-and-analysis-updates-in-copilot-code-review).
- **Block pull requests with exposed secrets from merging.** Repos can now enforce a merge block when secret scanning detects an exposed credential in a PR, closing a common security gap. Source: [GitHub Changelog, 2026-09-09](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging).
- **Refreshed repository pull requests page (public preview).** The PR list view got a UI refresh for easier scanning and filtering. Source: [GitHub Changelog, 2026-09-10](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview).
- **Control GitHub Actions cache access with `cache-mode`.** Workflow authors can now set explicit read/write cache permissions per job, reducing accidental cache poisoning risk. Source: [GitHub Changelog, 2026-09-10](https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode).
- **Agentic workflows: AI-powered repo automation in GitHub Actions.** Community "agentic workflows" are markdown-defined automations (issue triage, daily reports, compliance checks) that run coding agents via GitHub Actions, triggered by schedules, events, or slash commands. Source: [Awesome GitHub Copilot Learning Hub — Agentic Workflows](https://awesome-copilot.github.com/learning-hub/agentic-workflows/).
- **Decoding the new AI lingo.** A plain-language explainer of terms developers now see in AI tooling docs — loops, harnesses, squads, hill climbing. Useful vocabulary primer for anyone new to agentic coding tools. Source: [GitHub Blog, 2026-09-02](https://github.blog/ai-and-ml/decoding-the-new-ai-lingo-loops-harnesses-squads-hill-climbing-oh-my/).
